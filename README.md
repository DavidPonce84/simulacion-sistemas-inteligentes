# Simulación del aula — Sistemas Inteligentes (MIA · UDLA)

Maqueta de revisión que muestra cómo se ve la materia **Sistemas Inteligentes** desde el aula
virtual del estudiante, y qué cambia con la propuesta de actualización.

## Contenido

| Archivo | Qué es |
| :--- | :--- |
| `index.html` | Simulación del aula: recorrido por las 4 semanas con conmutador **antes / después** |
| `propuesta/Propuesta_SI_Cambios_Aula.docx` | Documento de propuesta para revisión y aprobación (mapeo antes/después) |
| `propuesta/sistemas-inteligentes.cambios-aula.md` | Fuente editable en texto de la misma propuesta |

## Cómo verlo

**Opción 1 — abrir el archivo:** descargar `index.html` y abrirlo con doble clic en cualquier
navegador. No requiere instalación ni conexión.

**Opción 2 — vista en línea:** si el repositorio se publica con GitHub Pages, la simulación queda
accesible como página web.

## Qué muestra la simulación

- El cascarón del aula (barra superior, navegación del curso e índice lateral) replicando la
  interfaz institucional.
- Las tres secciones reales de cada semana: **Materiales y actividades pre sesión**,
  **Encuentro sincrónico** y **Material y actividades post sesión**.
- El conmutador **Aula actual (antes) / Aula propuesta (después)** para comparar el cambio.
- Las vistas **Tareas** y **Calificaciones** con la tabla `Descripción | Ponderación`.
- La **secuencia habilitante**: cada entregable indica el concepto que exige y en qué semana se
  enseña antes de pedirlo.

## Alcance y estado

- Documento de **trabajo y revisión**; no es un documento oficial ni reemplaza al sílabo registrado.
- Las ponderaciones se mantienen en **10 / 15 / 20 / 20 / 10 / 25 = 100 %** en ambos modos: cambia
  la evidencia que se entrega, no el porcentaje.
- Los contenidos provienen del **sílabo registrado** (citas literales) y de la propuesta de
  actualización.
- Las fechas límite se muestran como referencia de diseño («por definir en el aula»).
